Supported phones

Which phones it runs on

OBSIDIAN is built for Google Pixel phones, one model at a time. A phone is only listed as ready once the build has been installed on that phone and used. Everything else is named here as what it is, being built or being tested, so you can see what is coming without being sold it early.

Where each phone stands

Today there is one phone you can install on. Three more are on the way.

Pixel 8 Ready

Built, installed and used on the real phone. This is the phone to buy if you want OBSIDIAN today. Google supports it with firmware and security updates until October 2030, and it has memory tagging, which OBSIDIAN switches on.

Pixel 9 In testing

The build is finished and the whole install has been proved step by step against a stand in for the phone, but it has not yet been installed on a real Pixel 9. It will be offered the day that test passes. Google supports it until August 2031, and it has memory tagging.

Pixel 7 Being built

Being built now, and then it has to be tested on the phone like the others. Be aware it is the weaker choice: no memory tagging in its processor, and Google's updates stop in October 2027, which is also when OBSIDIAN would stop being able to keep it fully secure.

Pixel 6 Being built

Being built now, and then tested on the phone like the others. Read this before you plan around it: Google's updates for the Pixel 6 stop in October 2026, which is this month, and it has no memory tagging. After that date the firmware underneath OBSIDIAN stops being fixed, so this build is for trying OBSIDIAN on a phone you already own, not for buying one to rely on.

Only the Pixel 8 can be installed at the moment. If a phone is not ready, the installer says so and changes nothing on it.

Check your phone first

It is the plain model

Open Settings, then About phone. The model should read Pixel 6, Pixel 7, Pixel 8 or Pixel 9 with nothing after it. The Pro, a and Fold versions look similar but are different phones inside, and each would need its own build and its own testing.

It can be unlocked

Connect it to Wi-Fi, then tap Build number seven times in About phone. In Settings, System, Developer options, the OEM unlocking switch has to turn on. If it stays grey once the phone has been online, it is locked to a mobile network and cannot take OBSIDIAN.

Buying second hand

Make sure the phone has been reset and removed from the previous owner's Google account, and ask to see the OEM unlocking switch on before you pay. A phone still tied to someone else's account cannot get far enough into its settings to be unlocked.

Why these phones

A private phone is only as strong as the hardware under it. These are the reasons, in plain terms.

They can be locked with a key that is not Google's

Most phones either refuse a different operating system or can never be locked again once one is installed. Pixels accept another key, so after installing, the bootloader can be locked and the phone will refuse anything not signed with that key.

A separate security chip

The Titan M2 chip holds the keys that protect your data and limits how quickly a PIN can be guessed, so a stolen phone cannot be opened by trying every number in turn.

Memory tagging in the processor

The Pixel 8 generation was the first with processors that can tag memory, which stops a large family of attacks that work by corrupting it. OBSIDIAN has it switched on, for the operating system and for Obsidian Chat. The Pixel 7 and Pixel 6 cannot do this, which is the main reason they are the weaker choices.

You can see what it started

When a Pixel runs an operating system other than Google's, it shows the full fingerprint of the key it started with. Once release keys exist we will publish ours, so you can compare the two and know the phone is running what we released.

Updates for years, and a known end date

Google provides firmware and security updates until August 2031 for the Pixel 9 and October 2030 for the Pixel 8. OBSIDIAN depends on those, so that is also how long each phone can be kept fully secure. For the Pixel 7 that date is October 2027, and for the Pixel 6 it is October 2026, which is why the newer phones are the ones worth buying.

Not supported

Pro, a and Fold versions

Close relatives with different hardware inside, such as the Pixel 8 Pro and the Pixel 8a. Each needs its own build and its own testing, and none has been done.

Other Pixel models

More may follow. None will appear as ready on this page until it has been built and used on the real phone.

Phones from other makers

Not planned. The reasons above are the standard, and most phones do not meet it.
